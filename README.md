# НЛТУ · Навчальний простір

Статичний HTML/CSS/JavaScript застосунок без збірки та зовнішніх залежностей. Розклад, навчальний план, журнал і експорт XLSX працюють у браузері.

## Запуск

Відкрийте `index.html` для звичайного перегляду або запустіть локальний сервер для PWA:

```sh
cd /Users/oleksii/NLTU_schedule
python3 -m http.server 8000 --bind 127.0.0.1
```

Відкрийте http://127.0.0.1:8000. Кнопка встановлення доступна в бічній панелі та внизу сторінки. На iPhone: Safari → Поширити → На початковий екран. PWA потребує HTTPS або localhost; відкриття файлу напряму не активує service worker. Перший запуск потребує мережі, наступні працюють із кешем. Нативного віджета iOS/Android немає.

## GitHub Pages

Завантажте вміст `nltu-site.zip` у корінь репозиторію. Settings → Pages → Deploy from a branch → виберіть гілку та `/ (root)`. Усі шляхи відносні: підтримується адреса `https://username.github.io/repository/`. Збірка не потрібна. Публікацію в GitHub у цьому завданні не виконано.

## Можливості

- 6 аркушів Excel, 62 групи/підгрупи. Фільтри за напрямом, групою, підгрупою або викладачем; пошук викладача.
- На широкому екрані тижнева сітка, на телефоні картки за днями. Типи занять розрізняються текстом і кольором.
- Непарний/парний тиждень обчислюється від понеділка тижня початку навчання. Початкову парність можна змінити.
- План бакалаврату 187/G14: чотири курси, семестри й категорії. Це орієнтовний перелік із наданого Markdown, не затверджений план. Категорії — редакційна класифікація; вибіркові дисципліни без визначеного семестру позначені.
- Журнал: викладач → його група → його дисципліна. Список студентів через кому/новий рядок, необов’язковий номер підгрупи перед прізвищем. Без номера показуються всі заняття групи.
- Журнал враховує Н/П, об’єднані заняття, індивідуальні підгрупи та період сесії. Модульний період не скасовує занять. Контрольні колонки — остання дата кожного з двох модулів й перша дата сесії; колонки розташовані хронологічно.
- Ручні оцінки від налаштовуваного мінімуму (типово 1) до 5, деморозподіл цілочисельної суми на вибрані типи занять. Для кожного студента сума розподілу точно дорівнює заданій. Значення двох модулів вводяться окремо (до 50 балів за кожен модуль), оцінка за сесію — вручну. Повторний розподіл змінює лише вибрані типи та модуль; попередні оцінки інших типів залишаються.
- XLSX із числовими оцінками, підсумками, замороженими заголовками та фільтром; підсумки експортуються як значення на момент завантаження.
- Збереження на пристрої через localStorage, резервна копія JSON і відновлення. Синхронізації між пристроями та облікових записів немає. Для перенесення використовуйте резервну копію.

## Джерела й неоднозначності

Дані з `rozklad_nni_dtd 26-27 осінь.xlsx` та `nltu_187_bakalavrat_predmety.md`. Оригінали не змінено.

- `л.` трактовано як лабораторну за вимогою користувача; `пр.`, `п.`, `практ.` — практичні; без префікса — лекція.
- Вертикальне об’єднання розгортається на Н/П, горизонтальне — на групи/підгрупи під ним. Повторні записи однієї пари об’єднуються в картку зі списком груп.
- Дні самостійної підготовки не є парами й не включаються до журналу.
- На аркуші ТДБ заголовок 2025/2026 суперечить назві файлу. Дані показано з відповідною приміткою.
- `ДТС, маг!F64:F65` — два записи матеріалознавства поза сіткою, без дня/часу; виключено.
- `ДТС, маг!G24` — хімія дерев у колонці без заголовка групи; виключено до уточнення.
- Помилки та варіанти написання імен у джерелі не виправляються здогадками. Наприклад, «Салапак» і «Саоапак» залишаються різними записами.
- Скорочені назви предметів і час п’ятої пари 16:20–17:35 збережено.

Повторний імпорт: `python3 scripts/import_schedule.py` (потрібен openpyxl; шляхи джерел указані у скрипті). Для оновлення розгорнутого сайту також змініть версію кешу у `sw.js`.

## Перевірка

`node tests.cjs` перевіряє імпорт, Н/П, від’ємний зсув тижня, зміни першої парності, підгрупи, виключення сесії, розбір студентів, точні суми демобалів і створення XLSX. Контрольний приклад: Інженер граф, ДТ-12 — 16 лекцій і 8 лабораторних за дефолтний семестр. XLSX додатково прочитано openpyxl; браузерний експорт перевірено на двох студентах, підсумки по 50 після переходу на шкалу 1–5.

## Оновлене компонування

Навчальний план показує всі чотири курси: загальні дисципліни помаранчеві, профільні зелені, вибіркові фіолетові. Кредити відсутні в джерелі, тому показано «—». Налаштування журналу розміщено горизонтально над таблицею. Колонки по 30 px, заголовки дат і типів повернуто на 90°, інші підгрупи позначено темними клітинками. Excel також має вузькі колонки, повернуті заголовки та темні клітинки.

Деморозподіл перевіряє досяжність суми: для N занять дозволено від N × мінімум до N × 5. Якщо сума недосяжна, оцінки не змінюються. Старі оцінки поза новою шкалою збережено й позначено червоним; експорт блокується до виправлення.
