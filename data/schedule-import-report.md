Разом: **8169 записів**, **31 аркуш**, **372 назв груп/підгруп**. Один запис — одна пара для однієї колонки групи та однієї парності тижня. Щотижнева пара має два записи, спільна для підгруп — окремий запис для кожної підгрупи. Це не кількість унікальних занять у календарі.

У БММ є дубль заголовка в одному аркуші та дві назви груп на різних аркушах. Тому в реєстрі 375 джерельних груп проти 372 нормалізованих назв. Порожні колонки з підписами також залишено в реєстрі.

## Файли

- `schedule.js` — оновлений `window.SCHEDULE`, збережено попередні поля для сумісності.
- `schedule.json` — ідентичний набір даних у чистому JSON.
- `schedule-import-report.json` — покриття імпорту, проблемні комірки, виключені записи, первинні тексти й розібрані поля.

## Ідентифікація та походження

| Поле | Значення |
|---|---|
| `instituteId` | `lspg`, `imakit`, `dtd`, `knit`, `bmm`, `snap`; є в заняттях, групах і джерелах |
| `sourceId` | Наприклад, `knit-2026-autumn`; посилання на `sources[]` з файлом, SHA-256 і переліком аркушів |
| `sourceFile` | Точна назва Excel-файлу |
| `sourceSheet` | Точна назва аркуша, включно з пробілами у джерелі |
| `cell`, `sourceRange` | Адреса первинної комірки та її об’єднаний діапазон |
| `rawSource` | Дослівний текст комірки, включно з переносами рядків |
| `raw` | Той самий текст зі згорнутими пробілами |
| `recordId` | Унікальний ключ розгорнутого запису, включає джерело, комірку, колонку групи та тиждень/рядок |
| `sourceCellId` | Ключ джерельної комірки; може повторюватися в кількох групах і тижнях |
| `qualifiedGroupId` | Інститут + нормалізована назва групи, наприклад `knit:КН-11/1` |
| `sourceGroupId` | Інститут/файл + аркуш + комірка заголовка; відрізняє дублікати джерельних колонок |
| `groupHeaderCell`, `rawGroup` | Адреса та оригінальний підпис групи |
| `coveredCell` | Комірка конкретної групи/тижня всередині merge; є для нового імпорту |
| `typeMarker`, `typeBasis` | Первинне позначення типу і правило його трактування |

Для фільтрації інституту достатньо `lesson.instituteId`. Для груп із неоднозначними/повторними назвами потрібно додатково враховувати `sourceGroupId`. `id` у старих записах ДТД збережено; він позначає джерельну комірку і не є унікальним ключем розгорнутого запису. Для унікальності використовуйте `recordId`.

## КНІТ

- Розібрано всі 5 аркушів: КН, ІСТ, ІПЗ, КІ, КБ.
- Усі **627 непорожніх комірок із заняттями** перенесено в **1147 записів**. Нерозібраних комірок КНІТ немає.
- Явні `лек.`, `лекція`, `лекція_` → `lecture`; `лабораторна`, `лабораторна_` → `lab`; `практичні_` → `practice`.
- Підсумок: **508 лабораторних**, **151 практичний**, **488 записів lecture**, з яких **19 записів адаптаційного курсу без позначки типу**. Для них залишено сумісне умовне значення `lecture` з `typeBasis: legacy-default-no-marker`.
- `_ч` → `parity: н` (чисельник); `_з` → `parity: п` (знаменник). Оригінальний маркер збережено в `parityMarker`.
- `КН-11-1` нормалізовано в `КН-11/1`. Магістерські позначення `(М)` збережено.
- Перелік потоків/груп на першому рядку комірки збережено як `declaredGroups`. Реальні групи для запису визначено за колонками та merge, а не за здогадкою зі скороченого переліку потоків.
- Враховано горизонтальні та вертикальні об’єднання; `---` і порожні рядки не перетворюються на заняття.
- У джерелі вказано лише час початку: `timeStart` заповнено, `timeEnd: null`. Час завершення не вигадано.
- Аудиторії на кшталт `12а`, `12б`, `В`, корпуси та викладачів розділено. Пропущені в Excel значення залишено порожніми.

## Інші інститути

- Попередні 1327 записів ДТД збережено без зміни жодного наявного поля; лише додано метадані походження.
- Для традиційного шаблону збережено раніше погоджене умовне правило: `л.` → `lab`, без префікса → `lecture`. Це НЕ твердження про офіційне значення позначки у всіх інститутах; `typeBasis` дозволяє пізніше переглянути правило без повторного читання Excel.
- Явне `лаб.` розпізнано як лабораторну. Підгрупи з тексту `(гр.ПС-14/1)` та `(гр.ІД-11/2)` виділено окремо.
- `conditions` зберігає прив’язку до модуля/парності з тексту; `teacherAssignments` — викладачів за модулями.
- `alternatives` містить альтернативне заняття для студентів, звільнених від основ національного спротиву. Його викладач не приписується основному заняттю.
- `options` зберігає варіанти вибіркових дисциплін із власними викладачами й аудиторіями, коли вони розділені у джерелі. Умови не підключено до логіки поточного інтерфейсу — це наступний етап.

## Покриття та уточнення

У п’яти нових файлах перевірено **4088 непорожніх комірок сітки**: **4004** розібрано як заняття, **59** є самостійною підготовкою, **4** є календарними примітками, **21** не мають надійного заголовка групи. Жодну непорожню комірку цієї області не відкинуто без категоризації.

21 запис без групи збережено в `unresolvedLessons` основного набору та у звіті. Вони не додані до `lessons`, щоб не призначати їх вигаданим групам. Окремо залишаються три раніше відомі проблемні комірки ДТД: `ДТС, маг!G24`, `F64`, `F65`, описані в `notes`.

Основні неоднозначності:

- БММ, `МО,МЗЕД,МК,ЛО 4,ск,5!G10,H10`: двічі `МК-12/1`. Не перейменовано другу колонку в `/2` без підтвердження.
- БММ: `МО-11` та `МО-12` присутні на двох аркушах; джерела збережено окремо.
- ІМАКІТ, `АК!T10`: `ІМ - 42/2`; `АК!X10`: `АКС-11` поруч із `АКС-11/2`. Підписи збережено без здогадок.
- ЛСПГ, `ЛГС,СПГС, маг!D33`: помилкове значення `3` замість парності. Для цього рядка використано явну праву позначку `V33 = н`; факт відновлення зазначено у звіті.
- Чотири календарні примітки містять по 12 дат і мають невідповідності з календарем 2026 року. Вони збережені структуровано в `calendarNotes`, позначені `needsReview`, не застосовані до занять.

## Виконані перевірки

- Унікальність усіх 8169 `recordId`; наявність інституту, джерела, групи й предмета.
- Дослівне зіставлення `rawSource` кожного запису з первинною Excel-коміркою; існування заголовка групи та посилання `sourceGroupId`.
- Незмінність усіх старих полів 1327 записів ДТД.
- КНІТ: відповідність парності суфіксам рядків, типів явним підписам, перевірка реальних merge `КБ!C4:D5` та однотижневої лабораторної `КН!S5`.
- Перевірка підгрупи з тексту `СНАП / ПС!I14 → ПС-14/1`.
- Баланс непорожніх комірок: розібрані + виключені + нерозв’язані = усі комірки області.
- Ідентичність вмісту JSON та JS-пакета; синтаксична перевірка `schedule.js`.

Наявний `scripts/import_schedule.py` усе ще імпортує тільки ДТД: його не змінено за вказівкою користувача. Запуск цього старого скрипта перезапише розширений набір; адаптація імпортера та фільтрів інтерфейсу залишена на наступний етап.
